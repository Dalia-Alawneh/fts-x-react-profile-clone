## 💡 Features

- Clean UI mimicking the original React profile on Twitter
- Fully responsive layout
- Dark mode design (similar to Twitter)
- Tailwind CSS utility-first styling
- Components structured for scalability and readability
- Clean and readable component structure


## 🛠️ Tech Stack

- **React**
- **Tailwind CSS**
- **Vite**

## **💻 Installation & Setup**  
To run the project locally, follow these steps:  

```bash
# Clone the repository
git clone https://github.com/Dalia-Alawneh/fts-x-react-profile-clone.git

# Install dependencies
npm install

# Start the development server
npm run dev
```
